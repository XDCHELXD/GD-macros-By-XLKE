# GD-macros-By-XLKE
В этом репозиторие я буду выкладывать макросы разнообразных уровней по игре Geometry dash, я прохожу многие уровни через шоукейс со спидхаком.Для того чтобы макрос появился в игре, нужно зайти в меню xdbot, нажать кнопку Load, нажать на плюс и выбрать из файлов скачанный макрос, далее нажать на Load рядом с макросом, нажать на кнопку Play, и там должна появиться галочка,после можно играть.
